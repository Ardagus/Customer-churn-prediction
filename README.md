# 📊 Предсказание оттока клиентов телеком-компании (Telecom Churn Prediction)

## 📌 Описание проекта
Цель данного проекта — на основе данных о клиентах сотовой компании построить модель машинного обучения для бинарной классификации, которая сможет предсказывать отток клиентов (Churn). Это классическая бизнес-задача, помогающая компаниям выявлять пользователей, готовых уйти, и вовремя предлагать им бонусы для удержания.

## 🛠 Стек технологий
* **Язык:** Python
* **Анализ данных:** `pandas`, `numpy`
* **Визуализация:** `matplotlib`, `seaborn`
* **Машинное обучение:** `scikit-learn`, `xgboost`

## 🗂 Данные
В работе использовался датасет `telecom_churn.csv` (3333 записи, 11 признаков). 
Признаки включают в себя информацию о тарифах, количестве минут разговора, расходах пользователя и обращениях в службу поддержки. Пропущенных значений в датасете не обнаружено.

## ⚙️ Что было сделано (Пайплайн)

1. **Разведочный анализ данных (EDA):**
   * Построена матрица корреляций. Выявлено, что признаки `AccountWeeks` и `DayCalls` не влияют на целевую переменную, поэтому они были исключены из обучения.
   * Изучены распределения непрерывных (KDE) и категориальных признаков.
2. **Предобработка:**
   * Данные разделены на обучающую и тестовую выборки с использованием стратификации (`stratify=y`) для сохранения баланса классов.
   * Выполнено масштабирование числовых признаков с помощью `MinMaxScaler`.
3. **Обучение моделей:**
   * Обучено 7 различных алгоритмов: **KNN, Логистическая регрессия, SVM, Random Forest, Градиентный бустинг (XGBoost), Деревья решений, Наивный Байес**.
4. **Оценка и настройка (Tuning):**
   * Подбор гиперпараметров для каждой модели выполнялся с помощью `GridSearchCV` и 5-фолдовой кросс-валидации.
   * Для анализа переобучения построены кривые обучения (`learning curves`).

## 🏆 Результаты
* В качестве основной метрики использовалась **Accuracy**, однако особое внимание уделялось метрике **Recall** (полнота), так как в бизнес-задаче удержания важнее минимизировать ложноотрицательные предсказания (не пропустить клиента, который хочет уйти).
* **Лучшие результаты показали модели:**
  * **SVM (Support Vector Machine):** Accuracy = 91%, Recall = 54%
  * **XGBoost:** Accuracy = 91%, Recall = 55%

**Вывод:** Модели отлично справляются с определением лояльных клиентов, но метрика Recall для класса "ушедших" остается на уровне 55%, что свидетельствует о сильном дисбалансе классов в исходных данных. В дальнейшем качество модели можно улучшить применением техник oversampling (например, SMOTE) или изменением порогов классификации.
